# 04. Дизайн-система

Mobile-first, эталонная ширина — **375px** (Экраны 1–6 из Модуля 7). Всё
ниже — конкретные токены как конфиг (Tailwind `theme.extend`), не
описательные пожелания: цифра — это цифра, редактируется в одном файле
`tailwind.config.ts`, не в разбросанных inline-стилях.

Шрифт — **Inter** (переменный шрифт, поддерживает Latin Extended + Cyrillic
в одном файле, важно для LV/RU без второго веб-шрифта и без FOUT между
языками). Системный стек — фолбэк.

## 1. Цветовые токены

Портал не окрашен в бренд ни одной автошколы (в т.ч. FORS) — это отдельная
самостоятельная площадка, что напрямую поддерживает принцип честности (визуально
нейтрален к партнёрам). Палитра — сдержанная, «государственно-справочная»
(референс по духу — GOV.UK, явно упомянутый в 7.1), не рекламная.

| Токен | HEX | Использование |
|---|---|---|
| `color-primary-600` | `#1D4E89` | Основной CTA, ссылки, активные состояния |
| `color-primary-700` | `#163C69` | Hover/active основного CTA |
| `color-primary-100` | `#E6EEF6` | Фон акцентных блоков (визард, калькулятор) |
| `color-neutral-900` | `#14181F` | Основной текст |
| `color-neutral-600` | `#4A5160` | Вторичный текст, подписи |
| `color-neutral-300` | `#C7CCD4` | Границы, разделители |
| `color-neutral-100` | `#F4F5F7` | Фон карточек, alt-строк таблиц |
| `color-neutral-0` | `#FFFFFF` | Базовый фон |
| `color-success-600` | `#1E7A46` | Позитивные статусы («выборка достаточная», «данные обновлены») |
| `color-success-100` | `#E6F4EC` | Фон позитивных `Callout` (добавлено в T-017 — до этого у `success` не было светлого фона, в отличие от остальных 3 тонов) |
| `color-warning-600` | `#B4740E` | Предупреждения («выборка мала», «сюда не входит») |
| `color-warning-100` | `#FBF0DC` | Фон предупреждающих `Callout` |
| `color-danger-600` | `#B3261E` | Ошибки форм, «недостоверно», блокирующие статусы |
| `color-danger-700` | `#891D17` | Hover/active тревожного CTA (добавлено в T-087 — первая кнопка на `danger`-тоне, до этого тон использовался только для текста/фона, не solid-кнопок) |
| `color-danger-100` | `#FBE9E7` | Фон блока ошибки |
| `color-focus-ring` | `#0B5FFF` | Кольцо фокуса — единственный цвет, зарезервированный **только** под focus-visible, нигде больше не переиспользуется |

Все пары текст/фон из таблицы проверены на контраст ≥ 4.5:1 (см. §5). Тёмная
тема не в скоупе Ф0–Ф5 — не проектируется и не запрашивается отдельно; если
понадобится, токены заведены так, что замена значений не требует переписывать
компоненты (это не решение «сделать потом», а следствие использования
токенов вместо хардкода).

## 2. Типографика

Шкала — модульная, база 16px, шаг ×1.25 (Major Third сокращённый под мобильный).

| Токен | Размер / line-height | Использование |
|---|---|---|
| `text-display` | 32px / 40px, 700 | H1 флагманских страниц («Почему 67% не сдают») |
| `text-h1` | 28px / 36px, 700 | H1 обычных страниц |
| `text-h2` | 22px / 30px, 700 | H2 |
| `text-h3` | 18px / 26px, 600 | H3, заголовки карточек |
| `text-body` | 16px / 24px, 400 | Основной текст |
| `text-body-sm` | 14px / 20px, 400 | Подписи, метаданные, `DataFreshness` |
| `text-caption` | 12px / 16px, 500 | Бейджи, лейблы форм |
| `text-numeric` | 20px / 28px, 700, tabular-nums | Цифры в калькуляторе/рейтинге — моноширинные цифры, чтобы колонки не «прыгали» |

От 768px (`md`) `text-display` → 40px/48px, `text-h1` → 32px/40px — единственное
масштабирование типографики по брейкпоинту, остальные размеры не меняются.

## 3. Шкала отступов

База 4px, используется только через шкалу — никаких «magic numbers» в CSS.

`space-0` 0 · `space-1` 4px · `space-2` 8px · `space-3` 12px · `space-4` 16px ·
`space-5` 20px · `space-6` 24px · `space-8` 32px · `space-10` 40px ·
`space-12` 48px · `space-16` 64px

Правило: горизонтальный паддинг контейнера на мобильном — `space-4` (16px);
вертикальный ритм между секциями страницы — `space-10` (40px) на мобильном,
`space-16` (64px) от `md`.

## 4. Радиусы, тени, брейкпоинты

| Токен | Значение |
|---|---|
| `radius-sm` | 6px — инпуты, чекбоксы |
| `radius-md` | 10px — карточки, кнопки |
| `radius-lg` | 16px — крупные блоки (карточка результата визарда) |
| `radius-full` | 999px — бейджи, пилюли фильтров |
| `shadow-sm` | `0 1px 2px rgba(20,24,31,0.06)` — карточки в состоянии покоя |
| `shadow-md` | `0 4px 12px rgba(20,24,31,0.10)` — поднятые элементы (открытый dropdown, sticky PhaseBar при скролле) |

| Брейкпоинт | Ширина | Комментарий |
|---|---|---|
| база (без префикса) | 375px+ | Эталон — мобильный, из прототипов Модуля 7 |
| `sm` | 640px | Крупный телефон/маленький планшет |
| `md` | 768px | Планшет — верхнее меню разворачивается из бургера |
| `lg` | 1024px | Десктоп — таблицы рейтингов получают доп. колонки |
| `xl` | 1280px | Широкий десктоп — контейнер получает `max-width: 1200px` и центрируется |

## 5. Состояния компонентов

Каждый интерактивный компонент из docs/05-components.md обязан явно
реализовать все применимые состояния — отсутствие состояния в коде считается
багом, а не «доделаем потом».

| Состояние | Правило |
|---|---|
| `default` | Базовый вид |
| `hover` | Только на устройствах с `hover: hover` (не эмулировать hover тапом на тач-экранах) |
| `focus` / `focus-visible` | Кольцо `color-focus-ring`, 2px, offset 2px — **видно всегда**, никогда не `outline: none` без замены |
| `active` | Визуально темнее/глубже на 1 шаг токена (`primary-600` → `primary-700`) |
| `disabled` | `opacity: 0.5` + `cursor: not-allowed`, убран из tab-order (`tabindex="-1"` только если элемент физически нельзя активировать) |
| `loading` | Скелетон повторяет геометрию финального контента (не спиннер по центру пустого блока) — критично для `RatingTemplate`/`CatalogTemplate`, где данные приходят асинхронно |
| `empty` | Текстовое объяснение + при наличии — действие («Пока нет отмеченных зон. Будьте первым») — см. правило пустых данных в docs/03-data-model.md |
| `error` | `color-danger-600` текст + `color-danger-100` фон, конкретная причина, не «что-то пошло не так» |

## 6. Требования доступности (обязательны, не «желательно»)

- **Контраст** ≥ 4.5:1 для текста ≤18px normal / 3:1 для крупного текста
  (≥24px или ≥18.5px bold) и для UI-элементов (границы инпутов, иконки-кнопки).
  Проверяется автоматически в CI (`axe-core` внутри Lighthouse CI, порог a11y
  ≥95 — docs/10-quality-gates.md).
- **Фокус виден всегда** — `:focus-visible` со своим кольцом (`color-focus-ring`),
  никогда не убирается глобальным `* { outline: none }`.
- **Тач-цель** ≥ 44×44px — включая область вокруг маленьких иконок (чекбоксы
  `PhaseBar`, кнопки закрытия). Если визуальный размер меньше — добавляется
  прозрачная область через padding, не через увеличение самой иконки.
- **Вся навигация проходима с клавиатуры**: Tab-порядок соответствует
  визуальному порядку, инструменты (визард, калькулятор, тренажёр) полностью
  управляемы без мыши — включая drag-подобные элементы (слайдер «Новое даётся:
  легко—тяжело» в калькуляторе обязан иметь клавиатурную альтернативу
  `ArrowLeft`/`ArrowRight` + видимое числовое значение, не только позицию
  бегунка).
- Языковой атрибут `<html lang="lv">`/`<html lang="ru">` выставляется на
  уровне страницы (не только `hreflang` в `<head>`) — это влияет на озвучку
  скринридером и перенос слов.

## 7. Что явно не проектируется в Ф0–Ф2

- Тёмная тема (см. §1).
- Анимации/переходы сверх `transition: color/background/opacity ~150ms` —
  никаких decorative-анимаций, слайдеров, каруселей (прямой запрет в 7.7
  Модуля 7 — «слайдер на главной», перенесён в CLAUDE.md как правило «никогда
  не делаем»).
