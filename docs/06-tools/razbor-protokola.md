# Инструмент: Разбор протокола (`p2-nenokartoju-protokols`, Ф4, ★★)

Пользователь вводит код(ы) нарушения из протокола экзамена CSDD (или
выбирает из справочника кодов, если протокол на руках, но коды непонятны) —
инструмент показывает человеческим языком, что пошло не так, типичную
причину ошибки и ссылку на конкретный материал для тренировки (навык из
Pillar 4, вопрос теории по теме). Данные — статический справочник кодов
нарушений (не требует Supabase), но сам инструмент помечен Ф4, потому что
логически привязан к разделу «Не сдал» и трекеру занятий (рекомендация после
разбора — «добавь это в план следующего занятия» пишет прямо в
`user_state.tracker_lessons`, что требует аккаунта). Детальный контракт
(edge cases для нескольких кодов одновременно, аналитика, критерии приёмки)
фиксируется отдельной задачей в docs/11-backlog.md на момент реализации Ф4.
