# Инструмент: Разбор протокола (`p2-nenokartoju-protokols`, Ф4, ★★)

Пользователь вводит номер пункта протокола экзамена CSDD (1–14, официальная
таблица «Protokols», см. T-102, docs/11-backlog.md) или выбирает из
справочника критериев, если протокол на руках, но формулировка непонятна —
инструмент показывает человеческим языком, что оценивает этот пункт, и
ссылку на конкретный материал для тренировки (навык из Pillar 4, вопрос
теории по теме), если такая связь честно устанавливается. Данные —
`src/content/exam-protocol/criteria.json` (Content Collection, T-102,
реальный источник — официальная презентация CSDD «Vadīšanas eksāmena
vērtēšana», 2018), не требуют Supabase — но сам инструмент помечен Ф4,
потому что логически привязан к разделу «Не сдал» и трекеру занятий
(рекомендация после разбора — «добавь это в план следующего занятия»
пишет прямо в `user_state.tracker_lessons`, что требует аккаунта, T-096,
транзитивно T-092/Supabase). Детальный контракт (сопоставление пунктов
протокола с материалами Pillar 4 — честно только там, где связь реальна,
не выдуманная; edge cases; аналитика; критерии приёмки) фиксируется
отдельной задачей в docs/11-backlog.md на момент реализации Ф4.
