# Инструмент: Каталог школ с фильтрами (`p3-katalogs`, Ф2, ★★)

## Вход

```ts
interface CatalogFilters {
  city_id?: string;
  gearbox?: "manual" | "automatic";
  language?: "lv" | "ru" | "en";
  category?: string; // "B", "A", ...
  sort: "rating" | "price-asc" | "name";
}
```

## Выход

Список школ (карточка: название, город, языки, коробка, цена или «по
запросу», бейдж партнёра при наличии, ссылка на `school-card`). Каталог
показывает **все** школы Латвии из открытых данных CSDD — не только
партнёров (см. `A-02`, docs/00-assumptions.md).

## Состояния

`default` (без фильтров, сортировка по рейтингу) → `filtered` →
`zero-results` → `loading` (skeleton-карточки той же геометрии).

## Формула

Без вычислений — чистая фильтрация `schools` по полям + сортировка:
`"rating"` использует `rank_score` из `ratings` (join по `school_id`, школы
без записи в `ratings` — в конец списка, не наверх и не наравне с
топ-позициями), `"price-asc"` — по `partner_price_eur`, если он `null` —
в конец списка (не приравнивается к 0).

## Edge cases

- Комбинация фильтров даёт 0 школ → `zero-results`: «Нет школ по этим
  критериям» + кнопка «Сбросить фильтры» (не тупик).
- Школа без `partner_price_eur` (не партнёр) → строка цены «по запросу»,
  карточка ведёт на `school-card`, где вместо кнопки «Записаться» — телефон/
  сайт из открытых данных, если есть, иначе просто адрес и рег. номер CSDD.
- Фильтры передаются как query-параметры (`?city=riga&gearbox=manual`), но
  **все комбинации, кроме пустого состояния, получают `noindex`** — правило
  7.3 Модуля 7 «инструменты — без пагинации и параметров в индексе», детали
  в docs/07-i18n-seo.md.

## Что при пустых данных

`schools` не загружен вовсе → каталог не рендерит пустой список молча, а
показывает `Callout tone="warning"` «Каталог временно недоступен» с
`DataFreshness`, датой последней успешной синхронизации.

## Аналитика

`catalog_viewed` · `catalog_filter_applied {filter, value}` ·
`catalog_zero_results {filters}` · `catalog_school_card_clicked {school_id,
is_partner}` · `catalog_sort_changed {sort}`.

## Критерии приёмки

- Партнёрская и обычная карточка школы используют идентичный HTML-шаблон и
  CSS-классы, разница — только наличие CTA «Записаться» (проверяется visual
  regression, не «на глаз»).
- Unit-тест фильтрации/сортировки на `fixtures/schools.json` +
  `fixtures/ratings.json`.
- Любая непустая комбинация фильтров генерирует `<meta name="robots"
  content="noindex">` — проверяется e2e-тестом.
- Каталог не требует JS для первого осмысленного рендера (SSR список школ
  без фильтров работает как обычная статическая страница, фильтрация —
  прогрессивное улучшение островом).
