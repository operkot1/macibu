# Экран «Не сдал экзамен» (`p2-nenokartoju-index`, Ф1, ★★)

Самый важный экран портала по прямому указанию задания — точка, где
пользователь либо остаётся, либо закрывает вкладку в состоянии стыда.

## Вход

Ничего не обязательно. Опционально (если известно из `user_state`) — дата
последней попытки сдачи теории, чтобы посчитать персональный дедлайн.

## Выход

- Статичный текст поддержки + национальная статистика («67% не сдают с
  первого раза»).
- Динамическая строка «Сегодня в Латвии экзамен не сдали ещё ~N человек».
- Основной CTA → `p2-nenokartoju-protokols` («Разобрать, что пошло не так»,
  доступен с Ф4 — до Ф4 CTA ведёт на `p2-nenokartoju-atgriezties`, статью «Как
  вернуться после провала», как временную замену).
- Второй, менее настойчивый CTA → истории тех, кто сдал с 3–5 раза
  (`static-content`, подборка внутри `p2-nenokartoju-atgriezties`).
- Блок «Когда можно пересдать» (статично: не раньше следующего рабочего дня,
  цена `driving-exam` из `csdd_tariffs`).
- Мини-инструмент «Посчитать мой дедлайн» — инпут даты сдачи теории → дата
  истечения годности.

## Состояния

`default` → `deadline-input-open` → `deadline-computed` → `deadline-warning`
(если до истечения <30 дней — красный `Callout`, но без давящего тона:
факт, не паника).

## Формула

```ts
function computeTheoryValidityDeadline(theoryExamDate: Date): Date {
  return addYears(theoryExamDate, 1); // "теория действует 1 год с даты сдачи"
}
```

Счётчик «~N человек сегодня» — **не** вычисляется в реальном времени на
клиенте (нет live-потока данных CSDD). Это редакционно обновляемая оценка:
`(годовое число несданных экзаменов по агрегату CSDD) / 365`, пересчитывается
вместе с обновлением `ratings`/статистики, хранится как обычное поле
Content Collections (не отдельный источник данных), с явной датой в
`DataFreshness`.

## Edge cases

- Нет даты сдачи теории → инструмент дедлайна просит ввести дату вручную,
  не блокирует остальной экран.
- CTA «Разобрать протокол» до Ф4 (пока инструмента `razbor-protokola` нет в
  проде) — ведёт на статью-заменитель, никогда не 404 и не «скоро».

## Что при пустых данных

Если агрегатная статистика для счётчика «~N человек» устарела/недоступна —
строка не рендерится вовсе (не показываем придуманное число), текст
переформулируется на «Две трети людей в Латвии не сдают экзамен вождения с
первого раза» (без суточного счётчика).

## Аналитика

`not_passed_screen_viewed` · `not_passed_cta_protocol_clicked` ·
`not_passed_cta_stories_clicked` · `deadline_calculated {days_remaining}`.

## Критерии приёмки

- Тон текста не осуждающий и не покровительственный — проверяется на
  контент-ревью, не автоматизировано.
- Одна основная кнопка, одна второстепенная ссылка — не два равнозначных CTA.
- Unit-тест на `computeTheoryValidityDeadline`.
- Экран доступен без единого клика на форму — на этом экране в принципе нет
  полей ввода персональных данных (только дата для дедлайна, не PII).
