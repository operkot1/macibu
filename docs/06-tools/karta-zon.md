# Инструмент: Карта экзаменационных зон (`p2-vadisana-zonas`, Ф4, ★★)

UGC-карта маршрутов и манёвров, которые реально встречаются на экзамене
вождения по городам — пользователи отмечают точки (`exam_zones`,
docs/03-data-model.md), редакция модерирует перед публикацией (SLA 48
часов). На старте Ф4 карта не пустая — засеяна редакционными данными
(`submitted_by: "editorial"`), чтобы день запуска не показывал пустую карту
без единой метки. Требует карт-провайдера без завязки на несовместимый с
CSP список (см. ограничения Artifact/окружения не относятся к продакшн-сайту,
но общий принцип «не тянуть тяжёлые сторонние SDK ради карты» — предпочтение
лёгкому вектору/OSM-based решению, а не тяжёлому JS SDK, чтобы не сломать
бюджет JS для этой страницы). Детальный контракт (формат геометрии маршрута,
модерационная очередь, антиспам) — отдельная задача в docs/11-backlog.md на
момент реализации Ф4.
