# Инструмент: Справочник штрафов (`p5-sodi`, Ф3, ★★)

Структурированный поиск/фильтр по реестру штрафов и нарушений (сумма,
количество пунктов, категория нарушения) — статический справочный контент
(Content Collections), обновляемый вручную при изменении законодательства,
без внешнего источника данных (в отличие от `csdd_tariffs`, это не CSDD-
выгрузка, а публичный реестр КоАП/ПДД Латвии, который команда поддерживает
редакционно). Связан с `p5-punkti` (калькулятор пунктов) через общий
справочник нарушений, чтобы не дублировать список кодов в двух местах.
Детальный контракт (структура фильтров, версионирование при изменении сумм
штрафов, аналитика) — отдельная задача в docs/11-backlog.md на момент
реализации Ф3.
