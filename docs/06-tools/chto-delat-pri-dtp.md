# Инструмент: «Что делать при ДТП» (`p5-csn-negadijums`, Ф3, ★★)

Интерактивный пошаговый гайд (аналог `StepList`, но с ветвлением по типу
ДТП — есть пострадавшие / нет пострадавших / только материальный ущерб) +
скачиваемый статический PDF-чеклист на LV и RU (см. `A-09`,
docs/00-assumptions.md — PDF не персонализирован, обновляется вручную при
смене регламента, а не генерируется под пользователя). Ключевое требование —
инструмент обязан открываться и быть читаемым в состоянии стресса
пользователя (крупный текст первого шага, минимум решений на экране,
телефон экстренных служб виден без скролла). Детальный контракт (ветвление
сценариев, обновление PDF при смене законодательства, аналитика) —
отдельная задача в docs/11-backlog.md на момент реализации Ф3.
