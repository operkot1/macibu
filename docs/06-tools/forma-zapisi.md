# Инструмент: Форма записи — партнёрская маршрутизация (`apply-index`, `apply-fors`, Ф3, ★★)

## БЛОКИРУЮЩЕЕ

Не выкатывается в прод, пока не закрыты 3 юридических пункта из
docs/09-legal-gdpr.md (явное согласие с перечислением получателей, договоры
о совместной обработке с каждой школой, политика конфиденциальности). Это
жёсткий гейт Definition of Done задачи, не рекомендация.

## Кратко

Форма собирает город/категорию/коробку/язык/срок/расписание, показывает
подходящие школы **только среди `is_partner: true`** (на старте — только
FORS, см. `A-02`), собирает имя/телефон и согласие, маршрутизирует лид.
Строка партнёра в списке подходящих школ не выделяется визуально относительно
других подходящих партнёров (когда их станет больше одного) — тот же принцип
честности, что в калькуляторе и рейтингах. `apply-fors/` — та же форма с
предзаполненным партнёром (используется в CTA со страницы `school-card-fors`
и из блока сравнения в калькуляторе). Детальный контракт (валидация полей,
формат передачи лида школе — email/API, retry-логика при сбое доставки,
аналитика по ступени 8 лестницы микроконверсий) — отдельная задача в
docs/11-backlog.md на момент реализации Ф3, обязательно в связке с
юридическим ревью.
