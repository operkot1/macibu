# Инструмент: Тренажёр теории — MVP (`p2-teorija-testi`, Ф1, ★★)

## Вход

Категория прав (по умолчанию `B`), кнопка «Начать без регистрации» — никаких
полей.

## Выход

Сессия из до 20 вопросов, по каждому — мгновенная обратная связь (верно/неверно
+ объяснение), в конце — счёт и предложение начать новую сессию.

## Состояния

`intro` → `in-progress` (X/20, прогресс-бар) → `answered` (correct/incorrect,
показан `explanation_lv`/`ru`) → `session-complete` (счёт, CTA «Ещё раз» и CTA
«Перейти к симулятору полного экзамена», если он уже в проде) → `category-empty`.

## Формула

```ts
function buildDailySession(all: TheoryQuestion[], category: string, seenToday: string[]): TheoryQuestion[] {
  const pool = all.filter(q => q.categories.includes(category) && !seenToday.includes(q.id));
  const size = Math.min(20, pool.length);
  return shuffle(pool).slice(0, size);
}
```

`seenToday` читается из `localStorage['portal:trainer:seen:{date}']`, чтобы в
рамках одного дня не повторять вопросы. Между днями история не хранится —
полноценный spaced repetition явно **вне скоупа MVP** (Ф1), фиксируется как
известное упрощение, не баг.

## Edge cases

- Доступно < 20 вопросов для категории → сессия короче, явная подпись
  «Сегодня доступно {N} вопросов» вместо тихого урезания.
- 0 вопросов для категории (например, C до наполнения банка) → состояние
  `category-empty`: «Этот раздел ещё не готов, доступно для категории B»
  + ссылка переключить категорию.
- Прогресс не теряется при случайном закрытии вкладки посреди сессии —
  текущая сессия (не только результат) пишется в `localStorage` на каждый
  ответ.

## Что при пустых данных

`theory_questions` пуст полностью (сбой контент-пайплайна) → тренажёр на
любой категории в состоянии `category-empty`, ссылка на `p2-teorija-eksamens`
(разбор экзамена — есть контент без вопросов) как временная альтернатива.

## Аналитика

`trainer_started {category}` · `trainer_question_answered {question_id,
correct}` · `trainer_session_completed {score, total, category}` ·
`trainer_category_unavailable {category}`.

## Критерии приёмки

- Unit-тест `buildDailySession`: нет повторов id в одной сессии, размер ≤ 20
  и ≤ размеру доступного пула.
- Работает полностью без аккаунта и без сетевого запроса после первой
  загрузки банка вопросов (офлайн-устойчивость сессии).
- JS-бандл — самостоятельный чанк, не подгружается на страницах, где
  тренажёр не используется (docs/10-quality-gates.md).
- Полностью управляем клавиатурой (выбор ответа — `Tab`+`Enter`/`Space`, не
  только клик мышью).
