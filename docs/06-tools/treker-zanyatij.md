# Инструмент: Трекер занятий (`p4-trakeris`, Ф4, ★★)

Единственный инструмент MVP-скоупа, требующий полноценного аккаунта
(Supabase Auth + RLS) — пользователь логирует занятия с инструктором (дата,
длительность, отработанные навыки из справочника `iemanas/*`), видит
прогресс по карте навыков (`p4-prasmju-karte`) и таймлайну дедлайнов
(`p4-termini`). Данные пишутся в `user_state.tracker_lessons` (docs/03-data-model.md)
с RLS-политикой `user_id = auth.uid()` — обязательный security review перед
релизом (см. риск в docs/00-assumptions.md, раздел рисков). Переход из
анонимного состояния (тренажёр теории, визард) в аккаунт должен происходить
без потери уже накопленного прогресса — email, сохранённый на ступени 3
лестницы микроконверсий (docs/08-analytics.md), используется как приглашение
привязать существующие локальные данные к новому аккаунту, а не начинать с
нуля. Детальный контракт — отдельная задача в docs/11-backlog.md на момент
реализации Ф4.
