import { getRatings } from "../../../lib/data";

export const ratings = getRatings();
export const sufficientSchools = ratings.entries.filter(
  (e) => e.subject_type === "school" && e.confidence === "sufficient",
);
export const avgPassRate = Math.round(
  (sufficientSchools.reduce((sum, e) => sum + e.pass_rate, 0) /
    sufficientSchools.length) *
    100,
);

Pēc CSDD oficiālās statistikas, aptuveni divas trešdaļas kārtotāju
nenokārto eksāmenu (teorijas vai praktisko) ar pirmo reizi. Tas nav
izņēmums — tā ir norma, ar ko sastopas vairākums. Tālāk — reālie
neveiksmes iemesli un ko var darīt jau iepriekš, lai nokļūtu tajā otrajā
trešdaļā.

## Kāpēc nenokārto teoriju

- **Priekšroka krustojumos** — īpaši neregulējamos un apļveida
  krustojumos.
- **Līdzīgas ceļa zīmes** — neskaidrība virspusējas mācīšanās gadījumā.
- **Ātruma ierobežojumi pēc ceļa veida** — atšķirīgas noklusējuma
  vērtības viegli sajaukt.
- **Signāli un apdzīšanas noteikumi** — tēma, ko bieži nenovērtē.

Detalizēts apskats — rakstā
[«Biežākās kļūdas teorijas eksāmenā»](/lv/csdd-eksameni/teorija/biezakas-kludas/).

## Kāpēc nenokārto braukšanu

- **Nepietiekama patstāvīgā prakse** — ja gandrīz visu laiku braukts pēc
  instruktora norādēm, eksāmena daļa bez norādēm
  ([«Patstāvīgā braukšana»](/lv/csdd-eksameni/vadisana/patstaviga-brauksana/))
  kļūst negaidīti sarežģīta.
- **Satraukums laukuma manevros** — obligātās figūras tehniski nav
  sarežģītas, bet tieši satraukums visbiežāk sabojā izpildījumu.
- **Nesagatavotība nepazīstamai videi** — reāli ceļi ir
  neparedzamāki nekā mācību maršruti.
