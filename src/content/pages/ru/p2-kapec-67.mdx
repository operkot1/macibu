import { getRatings } from "../../../lib/data";

export const ratings = getRatings();
export const sufficientSchools = ratings.entries.filter(
  (e) => e.subject_type === "school" && e.confidence === "sufficient",
);
export const avgPassRate = Math.round(
  (sufficientSchools.reduce((sum, e) => sum + e.pass_rate, 0) /
    sufficientSchools.length) *
    100,
);

По официальной статистике CSDD, около двух третей сдающих не проходят
экзамен (теоретический или практический) с первого раза. Это не
исключение — это норма, с которой сталкивается большинство. Дальше —
реальные причины провала и что можно сделать заранее, чтобы оказаться
в другой трети.

## Почему не сдают теорию

- **Приоритет проезда на перекрёстках** — особенно нерегулируемых и с
  круговым движением.
- **Похожие друг на друга дорожные знаки** — путаница при поверхностном
  заучивании.
- **Скоростные ограничения по типу дороги** — разные значения по
  умолчанию легко перепутать.
- **Сигналы и правила обгона** — тема, которую часто недооценивают.

Подробный разбор — в статье
[«Частые ошибки на теоретическом экзамене»](/ru/ekzameny-csdd/teoriya/chastye-oshibki/).

## Почему не сдают вождение

- **Недостаточно самостоятельной практики** — если почти всё время
  ездил по подсказкам инструктора, часть экзамена без указаний
  ([«Самостоятельный маршрут»](/ru/ekzameny-csdd/vozhdenie/samostoyatelnyj-marshrut/))
  становится неожиданно сложной.
- **Волнение на площадочных манёврах** — обязательные фигуры технически
  несложные, но именно волнение чаще всего портит исполнение.
- **Неготовность к незнакомой обстановке** — реальные дороги
  непредсказуемее учебных маршрутов.

## Что сделать заранее

1. Пройди [визард «Твой путь»](/ru/tvoj-put/) — увидишь весь путь и

   бесплатно, без регистрации.
3. Отметь прогресс в [чек-листе «9 шагов»](/ru/kak-poluchit-prava/9-shagov/).
4. Сравни реальную стоимость в [калькуляторе](/ru/avtoshkoly/kalkulyator/).
